# Data Science Project on Train Route Analysis and Journey Time Prediction

This project analyzes a train station-level dataset and will ultimately predict train journey duration using Linear Regression.

## Project Stages

1. Data Overview
2. Data Cleaning & Feature Engineering
3. Exploratory Data Analysis
4. Visualization & Pattern Analysis
5. Prediction Model Development
6. Final Journey Time Prediction System

## Project Structure

```text

outputs/
    figures/
    tables/
    models/

```

The current work begins with the data overview stage. Machine learning model development will be added in a later stage.
